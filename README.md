# 🤖 JobScout AI

### Autonomous AI Career Agent for Intelligent Job Discovery & Matching

JobScout AI is an autonomous career assistant that analyzes a candidate's CV, understands their skills and experience, generates targeted job-search queries, discovers real job opportunities, evaluates them using AI, and ranks the best matches.

---

## 🎯 Problem Statement

Finding suitable jobs manually is time-consuming. Candidates often search through multiple platforms, repeatedly enter different queries, and manually compare job requirements with their CV.

JobScout AI automates this process by allowing the user to upload a CV and letting an AI-powered career agent perform the complete workflow automatically.

---

## 🚀 Key Features

- 📄 PDF and DOCX CV upload
- 🧠 AI-powered CV analysis
- 👤 Automatic candidate profile generation
- 🔎 Dynamic job-search query generation
- 🌐 Real job discovery from online sources
- 📚 RAG-based CV information retrieval
- 🤖 AI-powered job evaluation
- 🎯 Job-to-CV matching
- 📊 Match percentage scoring
- 🏆 Automatic job ranking
- 💡 Explanation of why a job matches
- ✅ Matched skills
- ❌ Missing skills
- 📋 Required skills
- 💼 Experience requirements
- 🎓 Education requirements
- 📝 Job responsibilities
- 🔗 Direct View/Apply links
- 📱 Responsive dashboard UI
